# 👨‍💻 DevDetective - GitHub Profile Finder

DevDetective is a sleek web application that allows users to search for any GitHub profile and display detailed information like repositories, followers, location, and more — all in a visually appealing dark/light themed interface.

---

## 🌟 Features

- 🔍 Search any valid GitHub username
- 🌐 Fetches real-time data using GitHub API
- 🌗 Toggle between Dark & Light themes
- 📍 Displays:
  - Username and avatar
  - Public repos, followers, following
  - Location and join date
  - Company, website, and Twitter (if available)
- ❌ Graceful error handling if user is not found

---



## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)
- GitHub REST API
